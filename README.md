#  Kessoku Band Website

Projeto desenvolvido utilizando apenas HTML5 e CSS3 com o objetivo de apresentar a banda fictícia Kessoku Band, do anime e mangá *Bocchi the Rock!*.

## Sobre o Projeto

O site apresenta:

- História da banda
- Informações sobre as integrantes
- Músicas através de integração com Spotify
- Instrumentos utilizados pelas personagens
- Galeria de imagens

O foco do projeto foi praticar:

- Estruturação semântica em HTML
- Organização de conteúdo
- Estilização com CSS
- Responsividade básica
- Incorporação de mídia externa

---

## Tecnologias Utilizadas

- HTML5
- CSS3
